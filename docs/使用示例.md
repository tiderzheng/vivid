# 使用示例（瞬知 / Vivid）

这份文档给的是最常用的实际命令。

文档定位说明：

- 这里默认面向直接使用仓库的人，所以主入口统一写 `scripts/vivid_tool.*`
- 如果你是在 agent / skill 场景里调用，请改用 `skill/vivid-operator/scripts/vivid_operator.*`
- `vivid_operator.*` 会自动定位仓库，再转发到 `vivid_tool.*`

## 1. 查看当前路径和下载器

Windows:

```powershell
.\scripts\vivid_tool.ps1 -Action paths
```

Linux/macOS:

```bash
./scripts/vivid_tool.sh -Action paths
```

适合确认：

- 项目根目录
- 默认输出目录
- 内嵌下载器路径（`tools/bilibili/`、`tools/douyin/`）
- `ffmpeg` 路径

## 2. 先做环境检查

Windows:

```powershell
.\scripts\vivid_tool.ps1 -Action doctor
```

Linux/macOS:

```bash
./scripts/vivid_tool.sh -Action doctor
```

重点看：

- `python`
- `ffmpeg`
- `node`（如需下载抖音视频）
- `opencv`（会自动安装）
- 内嵌下载器（`tools/bilibili/`、`tools/douyin/`）

## 3. 处理 Bilibili 视频

Windows:

```powershell
.\scripts\vivid_tool.ps1 -Action quickread -Source "https://www.bilibili.com/video/BVxxxx"
```

如果接口提示未登录，可先扫码建立项目本地登录态：

```powershell
.\scripts\vivid_tool.ps1 -Action bili-auth-qrcode
.\scripts\vivid_tool.ps1 -Action bili-auth-poll -QrcodeKey "<qrcode_key>"
.\scripts\vivid_tool.ps1 -Action bili-auth-status
```

Linux/macOS:

```bash
./scripts/vivid_tool.sh -Action quickread -Source "https://www.bilibili.com/video/BVxxxx"
```

这条链路会：

- 使用完整 Cookie、本地二维码登录态或匿名指纹模式访问 Bilibili
- 下载媒体
- 再做转录 / OCR / 摘要

## 4. 处理 Douyin 视频

Windows:

```powershell
.\scripts\vivid_tool.ps1 -Action quickread -Source "https://v.douyin.com/xxxxx/"
```

Linux/macOS:

```bash
./scripts/vivid_tool.sh -Action quickread -Source "https://v.douyin.com/xxxxx/"
```

这条链路会：

- 使用内嵌的 `tools/douyin/douyin.js`
- 下载视频
- 再做转录 / OCR / 摘要

## 5. 处理本地视频

```powershell
.\scripts\vivid_tool.ps1 -Action quickread -Source "D:\videos\demo.mp4" -Platform local
```

## 6. 处理本地音频

```powershell
.\scripts\vivid_tool.ps1 -Action quickread -Source "D:\audio\demo.mp3" -Platform local
```

## 7. 指定 Whisper 模型

```powershell
.\scripts\vivid_tool.ps1 -Action quickread `
  -Source "D:\videos\demo.mp4" `
  -Platform local `
  -Model small
```

## 8. 指定输出目录

```powershell
.\scripts\vivid_tool.ps1 -Action quickread `
  -Source "D:\videos\demo.mp4" `
  -Platform local `
  -DataDir "D:\ai\quicker_video\Vivid\data"
```

## 9. 优先 OCR

```powershell
.\scripts\vivid_tool.ps1 -Action quickread `
  -Source "D:\videos\demo.mp4" `
  -Platform local `
  -PreferOcr `
  -VisionBackend internal
```

## 10. 智能推荐模式

```powershell
.\scripts\vivid_tool.ps1 -Action quickread `
  -Source "D:\videos\demo.mp4" `
  -Platform local `
  -AcquisitionMode smart
```

这条链路会：

- 先做本地硬字幕探测
- 命中硬字幕时优先 OCR
- 没命中时优先转录
- OCR 兜底仍保留

## 11. 强制 OCR

```powershell
.\scripts\vivid_tool.ps1 -Action quickread `
  -Source "D:\videos\demo.mp4" `
  -Platform local `
  -ForceOcr `
  -VisionBackend internal
```

## 14. Web UI 里通常怎么用

### 场景 A：处理本地视频

1. 打开 Web UI
2. 拖拽本地视频
3. 选择 `Whisper` 模型
4. 设置输出目录
5. 点开始

### 场景 B：处理视频链接

1. 打开 Web UI
2. 粘贴视频链接
3. 确认参数
4. 点开始

### 场景 C：批量处理多个链接

1. 打开 Web UI
2. 在“批量 URL”里每行粘贴一个链接
3. 一次设置 `Whisper`、输出目录、OCR 配置等参数
4. 提交后等待后台依次创建并执行任务

### 场景 D：批量导出历史任务

1. 在历史任务里勾选要导出的已完成任务
2. 可先用过滤框缩小范围，再点“选中当前筛选”
3. 点击“导出选中任务”
4. 浏览器会下载一个 zip，里面包含每个任务的 `artifacts/` 和 `manifest.json`

### 场景 E：失败后继续任务

1. 任务在转录或总结阶段失败后，打开该任务详情
2. 在“继续阶段”里选择要恢复的阶段
3. 点击“继续任务”
4. Web UI 会基于 `artifacts/run_state.json` 复用已完成阶段，不从头重跑
5. 详情页里的“失败链”会显示每一次失败、回退和对应错误

### 场景 F：配置 OCR API

1. 打开 Web UI
2. 填入 OpenAI 兼容 OCR API 参数
3. 可选择保存为默认配置
4. 再提交任务

## 15. 成功后看哪里

优先看这些字段：

- `result.source`
- `result.transcript`
- `result.summary`
- `result.artifacts`

产物目录里重点看：

- `quickread.md`
- `transcript.txt`
- `summary.md`
- `metadata.json`

## 16. 失败后看哪里

优先看：

- `ok`
- `exit_code`
- `error`
- `error_code`
- `result.error_summary`
- `result.failure_chain`

如果是下载失败，再看：

- `doctor`
- helper 路径
- `BILI_SESSDATA`
