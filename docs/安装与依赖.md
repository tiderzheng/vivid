# 安装与依赖（瞬知 / Vivid）

这份文档只回答一个问题：

**把瞬知（Vivid）跑起来，需要准备什么。**

## 基础环境

推荐环境：

- Windows 10 / 11
- Linux
- macOS
- Python 3.10+
- PowerShell 5+ 或 PowerShell 7+（Windows）

## 必需依赖

### 1. Python

需要系统里有可直接调用的 `python`（Python 3.10+）。

### 2. ffmpeg

用于：

- 音频抽取
- 音视频处理
- 转录前预处理

**瞬知**（Vivid） 的 `ffmpeg` 查找顺序：

1. `VIVID_FFMPEG_BIN` 环境变量
2. 系统 `PATH`

### 3. Node.js（可选但推荐）

用于运行 Douyin 下载器（`tools/douyin/douyin.js`）。

如果你不需要下载抖音视频，可以不安装 Node.js。

### 4. Python 包

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

重点包包括：

- `requests` - HTTP请求
- `openai-whisper` - 语音转录（会间接安装`torch`）
- `fastapi` / `uvicorn` - Web UI服务
- `yt-dlp` - 通用站点下载兜底

说明：

- `yt-dlp` 只用于通用站点兜底
- `Bilibili` 和 `Douyin` 使用内嵌下载器，不走 `yt-dlp`
- 内部 `Whisper` 转录会用到 `torch`
- `openai-whisper` 会间接安装 `torch`，但 `torch` 的 wheel 选择通常取决于 CPU / CUDA / 操作系统
- 因此项目没有在 `requirements.txt` 里硬编码 `torch` 版本
- 如果你只是 CPU 环境，通常可以直接执行 `pip install -r requirements.txt`
- 如果你需要指定 GPU / CUDA 版本，建议先按官方 `PyTorch` 安装说明装好对应版本的 `torch`，再执行 `pip install -r requirements.txt`

### NVIDIA GPU 提示

如果自动脚本检测到 **NVIDIA GPU**，会在安装 `requirements.txt` 之前主动停止，避免把 `torch` 静默装成 CPU 版。

你需要二选一：

1. CPU 路径

```powershell
$env:VIVID_TORCH_MODE = "cpu"
.\scripts\vivid_tool.ps1 -Action doctor
```

2. CUDA 路径

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 自动安装的依赖

### opencv

`opencv` 用于：

- 从视频中抽帧
- 支持内部 OCR 链路

如果环境里没有 `cv2`，**瞬知**（Vivid） 会自动尝试执行：

```powershell
pip install opencv-python -i https://mirrors.aliyun.com/pypi/simple/
```

你可以用下面的环境变量覆盖默认镜像：

- `VIVID_PIP_INDEX_URL`

## 内嵌下载器

Vivid 已内嵌以下下载器，开箱即用：

### Bilibili

- 内嵌路径：`tools/bilibili/bili23_agent_cli.py`
- 依赖：`requests`（已通过pip安装）
- 功能：视频下载、字幕提取

### Douyin

- 内嵌路径：`tools/douyin/douyin.js`
- 依赖：Node.js（需单独安装）
- 功能：无水印视频下载

### Generic

- 使用 `yt_dlp`（通过pip安装）
- 用于其他视频站点的通用下载兜底

## 可选依赖

这些不是主路径必需，但在回退模式下会用到。

### Ears4

用于：

- 内部转录失败时的兼容回退

### Eyes

用于：

- 内部 OCR 失败时的兼容回退

### BILI_SESSDATA

用于：

- 访问受限 Bilibili 内容（如需要登录才能观看的视频）
- 优先尝试获取 Bilibili 官方字幕

来源优先级：

1. `--sessdata`
2. `--no-sessdata`
3. `BILI_SESSDATA`

补充：

- `--sessdata` 会覆盖环境变量里的 `BILI_SESSDATA`
- `--no-sessdata` 会显式忽略环境变量里的 `BILI_SESSDATA`

如果你不知道怎么获取：

1. 登录 `bilibili.com`
2. 按 `F12` 打开开发者工具
3. 打开 `Application` 或 `Storage`
4. 进入 `Cookies` -> `https://www.bilibili.com`
5. 复制 `SESSDATA` 的值

如果统一控制面 `quickread` 返回 `error_code = "bili_sessdata_expired"`：

- 说明当前 `SESSDATA` 很可能已失效
- 应先让用户提供新的 `SESSDATA`
- 如果用户不提供，就使用 `--no-sessdata` 重新执行 `quickread`，显式忽略环境中的旧会话，再继续媒体下载 / 转录 / OCR 流程

## 推荐安装顺序

1. 安装 Python 3.10+
2. 安装 ffmpeg
3. （可选）安装 Node.js（如需下载抖音视频）
4. 执行 `pip install -r requirements.txt`
5. 跑 `doctor` 检查环境

## 运行前检查

这里默认写仓库内主入口 `scripts/vivid_tool.*`。
如果你是在 skill / agent 场景里运行，请改用 `skill/vivid-operator/scripts/vivid_operator.*`，它会负责仓库定位和参数转发。

Windows:

```powershell
.\scripts\vivid_tool.ps1 -Action paths
.\scripts\vivid_tool.ps1 -Action doctor
```

Linux/macOS:

```bash
./scripts/vivid_tool.sh -Action paths
./scripts/vivid_tool.sh -Action doctor
```

重点确认：

- `python` 可用
- `ffmpeg` 可用
- `node` 可用（如需下载抖音）
- `torch` 可用（如需使用内部Whisper）
- 内嵌下载器路径存在（`tools/bilibili/`、`tools/douyin/`）
- OCR / 转录配置文件存在

## 常见安装问题

### `opencv` 没装怎么办

一般不用手动处理，**瞬知**（Vivid） 会自动尝试安装。

### `doctor` 里 `ffmpeg=false`

说明当前没有找到 `ffmpeg`。

解决方式：

- 把 `ffmpeg` 加进 `PATH`
- 或设置 `VIVID_FFMPEG_BIN` 环境变量

### `doctor` 里 `node=false`

说明当前机器还不能运行 `douyin.js`。

如果你不需要下载抖音视频，可以忽略这个警告。

### `doctor` 里内嵌下载器路径不存在

正常情况下不应该出现，因为下载器已内嵌到 `tools/` 目录。

如果确实出现，请检查：

- 是否正确克隆了仓库（`tools/` 目录是否存在）
- 是否误删了 `tools/` 目录下的文件

## 自定义下载器

如需使用自定义下载器，可通过环境变量覆盖：

- `VIVID_BILI_SCRIPT` - 自定义Bilibili下载器路径
- `VIVID_DOUYIN_SCRIPT` - 自定义Douyin下载器路径
