# 摘要大纲升级设计

## 背景

当前摘要只有一句话、一个段落和若干要点。对 `vivid-operator` 的实际使用来说，这个结构不够支撑“直接把总结完整返回给用户”的场景，也不足以覆盖进一步学习、交叉验证和争议识别。

## 目标

把默认 AI 总结升级为固定六段式结构：

1. 标题
2. 内容概览
3. 核心观点
4. 争议点
5. 行动建议
6. 俏皮点评

同时要求 skill 明确约束 agent：读取 summary 结果后，必须完整返回以上六段，不能只摘一句话或几点要点。

## 兼容策略

- 程序内部新增结构化字段：`title`、`overview`、`core_points`、`controversies`、`action_suggestions`、`playful_comment`
- 保留旧别名：
  - `one_line` -> `title`
  - `detailed` -> 六段式正文拼接
  - `key_points` -> `core_points`
- checkpoint / summary.json / API 返回同时兼容旧字段，避免断点续跑和旧调用方直接失效

## 行动建议定义

`行动建议` 不是泛泛“可以了解更多”，而是要求给出可执行的后续动作，例如：

- 推荐相关阅读关键词 / 书单 / 综述 / 官方资料
- 推荐继续学习的知识点或课程方向
- 推荐证真方式，如查一手来源、数据源、论文、法规、官方公告、实验设计

## 非目标

- 不按 `language` 自动切多语言模板
- 不改总结 provider 选择逻辑
- 不新增新的 summary 页面路由
